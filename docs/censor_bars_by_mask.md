# Censor Bars By Mask

## 機能概要

`Censor Bars By Mask` は、入力画像のうちマスクで指定された領域を、複数の平行な帯状矩形で隠す ComfyUI ノードです。  
モザイクや単純な塗りつぶしではなく、いわゆるバーセンサ / 海苔に近い見た目を生成し、元画像へ合成します。

## 入力

| 名前 | 型 | 説明 |
| --- | --- | --- |
| `image` | `IMAGE` | 検閲帯を合成する入力画像 |
| `mask` | `MASK` | 帯配置の基準にするマスク。非ゼロ領域を隠す対象として扱います |
| `bar_color_r` | `INT` | 帯色の赤成分。`0` から `255` |
| `bar_color_g` | `INT` | 帯色の緑成分。`0` から `255` |
| `bar_color_b` | `INT` | 帯色の青成分。`0` から `255` |
| `opacity` | `FLOAT` | 帯の透明度。`0.0` から `1.0` |
| `angle_mode` | `STRING` | `manual` または `auto`。帯の向きを手動指定するか自動推定するかを選びます |
| `angle_deg` | `FLOAT` | `angle_mode=manual` のときに使う帯角度。単位は度です |
| `angle_offset_deg` | `FLOAT` | 最終角度への補正値。既定値は `90` 度で、`auto` 時は主軸直交方向を初期値にします |
| `bar_width` | `FLOAT` | 帯の基本幅。`1` pixel 以上 |
| `bar_spacing` | `FLOAT` | 帯同士の基本間隔。`0` pixel 以上 |
| `width_jitter` | `FLOAT` | 帯幅へ加えるランダム変動量 |
| `spacing_jitter` | `FLOAT` | 帯間隔へ加えるランダム変動量 |
| `seed` | `INT` | jitter を再現可能にする乱数シード |

## 出力

| 名前 | 型 | 説明 |
| --- | --- | --- |
| `image` | `IMAGE` | 検閲帯を合成した画像 |

初版では `image` 出力のみを公開します。`overlay_mask` や `overlay_preview` は将来の拡張候補です。

## 処理仕様

- マスクは帯を置くための基準として使い、マスク形状そのものを直接塗りつぶしません
- 帯は平行な長方形として生成し、複数本を並べてバーセンサ風の見た目を作ります
- 生成した帯パターンは、最終的に元のマスク非ゼロ領域で切り抜いて使用します
- デフォルト動作では、帯はマスク外へはみ出しません
- マスクが複数領域でも、初版はマスク全体をまとめて 1 つの対象として扱います
- 合成は `opacity` を用いたアルファ合成で行います

## 角度仕様

### 手動角度

- `angle_mode=manual` の場合、`angle_deg` をそのまま帯角度として使用します
- `angle_offset_deg` は最終角度へ追加され、既定値は `90` 度です

### 自動角度

- `angle_mode=auto` の場合、マスク非ゼロ画素の分布から主軸方向を推定します
- 初版では PCA ベースの主軸推定を使い、実装の安定性を優先します
- `angle_offset_deg` の既定値は `90` 度で、初期状態では主軸直交方向の帯になります
- 小さすぎるマスク、ほぼ円形のマスク、方向性が弱いマスクでは `0` 度へ安全にフォールバックします

## 帯生成仕様

- 帯は回転後もマスク領域を覆えるよう、回転を考慮した範囲で生成します
- `bar_width` と `bar_spacing` に対して jitter を各帯ごとに適用します
- jitter 適用後も安全のため、`bar_width >= 1`、`bar_spacing >= 0` にクランプします
- `seed` を固定すれば、同じ入力に対して同じ帯配置を再現できます
- 内部的には計算量を抑えるためにマスク外接矩形で計算範囲を絞りますが、最終的な表示範囲は元マスクで制限します

## 使用例

### 基本例

顔や識別したくない領域に白マスクを与え、`bar_width=18`、`bar_spacing=8`、`opacity=1.0` に設定すると、マスク内部に黒いバーセンサ風の帯を複数本重ねて隠せます。

### 斜め帯の例

`angle_mode=manual` として `angle_deg=30` を指定すると、斜め方向の帯を生成できます。単純な水平帯よりも、演出的な検閲表現に向きます。

### 自動角度の例

細長いマスクに対して `angle_mode=auto` を使うと、既定では主軸直交方向の帯を生成します。主軸に沿わせたい場合は `angle_offset_deg=0` を指定してください。

### 揺らぎを加える例

`width_jitter` と `spacing_jitter` を少し上げると、帯幅や間隔が少しずつ変化し、機械的すぎない海苔表現になります。

## 注意点 / 制約

- 空マスクの場合は例外を出さず、入力画像をそのまま返します
- `opacity=0` の場合も結果は元画像と同じです
- マスク解像度が画像と異なる場合は、画像サイズに合わせて内部で補間します
- 自動角度は厳密な画像解析よりも、自然に見える帯方向と安定動作を優先します
- 初版では連結成分ごとの個別処理は行いません
- マスク外へ帯を拡張する動作は、将来のオプションとして別途検討します
