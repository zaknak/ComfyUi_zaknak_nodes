# Mosaic By Mask

## 機能概要

`Mosaic By Mask` は、入力画像のうちマスクで指定された領域にだけモザイクを適用する ComfyUI ノードです。  
白いマスク領域を対象としてモザイクを適用し、必要に応じてマスク反転と境界ぼかしを行います。

## 入力

| 名前 | 型 | 説明 |
| --- | --- | --- |
| `image` | `IMAGE` | モザイク処理を行う入力画像 |
| `mask` | `MASK` | モザイク適用範囲を示すマスク。白い領域ほど強く適用されます |
| `invert_mask` | `BOOLEAN` | `true` の場合、入力マスクを反転して使用します |
| `pixel_size` | `INT` | モザイクの 1 ブロックサイズ。`1` 以上の整数を指定します |
| `edge_blur` | `FLOAT` | 元画像とモザイク画像の合成境界をぼかす量。`0` 以上を指定します |

## 出力

| 名前 | 型 | 説明 |
| --- | --- | --- |
| `image` | `IMAGE` | モザイク適用後の画像 |
| `mask` | `MASK` | 反転と境界ぼかしを反映した、実際に合成へ使用した最終マスク |

## 処理仕様

- 白いマスク領域をモザイク対象とします
- `invert_mask` を有効にすると、反転後のマスクを対象として使います
- `pixel_size` が大きいほど、モザイクは粗くなります
- `edge_blur` はモザイク境界だけを滑らかにし、モザイク領域全体を別途ぼかすことはしません
- 出力マスクは、処理画像の合成に使用した最終状態のマスクです

## 使用例

### 基本例

人物写真に対して顔部分だけを白マスクで指定し、`pixel_size=16` を設定すると、顔部分だけにモザイクを適用できます。

### 反転例

背景側を残して主要被写体以外にモザイクをかけたい場合は、被写体マスクを入力して `invert_mask=true` を有効にします。

### 境界を自然にする例

切り抜き境界が目立つ場合は、`edge_blur` を少し上げることで、元画像とモザイク画像の接続を滑らかにできます。

## 注意点 / 制約

- `pixel_size=1` の場合、見た目の変化はほぼありません
- マスク解像度が画像と異なる場合は、画像サイズに合わせて内部で補間します
- 境界ぼかしを強くすると、モザイクの適用範囲が見た目上やや広がることがあります
